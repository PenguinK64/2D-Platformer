Puzzle Platformer

A 2D puzzle platformer made from scratch in C using Raylib for the university course Games Programming, AI and Physics. This project was developed as part of an assignment focused on experimenting with physics concepts to create a playable game.



Controls:

 Left / Right Arrow / A / D – Move
 Up Arrow / Space – Jump
 Enter – Reset push boxes
 P – Pause

 
 
Features:

 Physics-based movement and jumping
 AABB collision detection and resolution
 Pushable box and pressure plate puzzles
 Bounce pads
 Collectables and scoring
 Death and respawning
 Coyote time and jump buffering
 Variable Jump Height and Apex Hang Time
 Follow camera
 Win/lose and game states
